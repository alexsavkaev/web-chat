# OpenSpec

This directory contains the project contract and the initial change specification.

## Workflow

1. Read `project.md` for architecture and project-wide constraints.
2. Read `changes/initial-web-chat/proposal.md` for scope.
3. Read `changes/initial-web-chat/design.md` before implementation.
4. Execute `changes/initial-web-chat/tasks.md` in order, keeping module boundaries explicit.
5. Update the artifacts when implementation decisions materially change the design.
